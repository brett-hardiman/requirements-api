Input — Project Description

A caller sends a plain-English description of a project. This is the raw text that kicks off the whole pipeline — no special formatting required. You can also pass an optional num_stories field to control how many user stories come back (defaults to 5).

Concepts You'll Learn
🛣️
Routing
The @app.post("/generate-requirements") decorator maps a URL path to a Python function. That's a route.
📐
Pydantic Models
BaseModel classes define the shape of your request and response. FastAPI uses them to auto-validate incoming JSON and auto-document your API.
🔑
API Keys & .env
Your Anthropic API key lives in a .env file, never hardcoded. os.environ.get() reads it safely at runtime.
🧱
Structured Output
You prompt Claude to return only JSON, then parse and validate it with your Pydantic model before sending it back to the caller.
💥
HTTP Exceptions
HTTPException(status_code=500) is how you signal errors to API callers. You'll learn the common status codes naturally here.
🏥
Health Check
The GET /health endpoint is a convention — it lets infrastructure and humans quickly verify the API is alive.
How To Run It
01
Install dependencies — pip install -r requirements.txt
02
Create a .env file — add your Anthropic API key: ANTHROPIC_API_KEY=sk-ant-...
03
Start the server — uvicorn main:app --reload — your API is now live at localhost:8000
04
Open the auto-docs — go to localhost:8000/docs in your browser. FastAPI generates interactive Swagger docs automatically. Test your endpoint right there, no Postman needed yet.
05
Send your first request — paste a project description, hit Execute, and watch structured user stories come back.
